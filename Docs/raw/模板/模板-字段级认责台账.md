# 字段级认责台账模板

## 📋 台账字段说明

| 字段名 | 说明 | 示例 |
|--------|------|------|
| 表名 | 数据库表名 | customer |
| 字段名 | 标准字段名 | customer_name |
| 字段业务含义 | 用一句话说明 | 客户姓名 |
| 数据域 | 所属业务域 | 客户域 |
| Owner部门 | 负责部门 | 零售业务部 |
| Owner姓名 | 负责人 | 张总 |
| Steward姓名 | 日常对接人 | 李四 |
| 数据类型 | 标准类型 | 字符串(50) |
| 是否必填 | 是否允许为空 | 是 |
| 质量标准 | 质量检核规则 | 非空率100% |
| 当前质量得分 | 最新得分 | 95 |
| 状态 | 有效/待调整/废弃 | 有效 |

## 📎 使用方法

1. 在元数据管理平台维护，或Excel维护
2. 字段新增/变更时，3个工作日内更新台账
3. 每季度复核一次Owner准确性
4. 质量得分每月更新
