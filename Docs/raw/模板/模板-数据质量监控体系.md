## 一、监控体系总体框架

### 1.1 四层架构

```
数据质量监控体系
│
├── 第一层：检核规则层（规则引擎）
│   ├── 完整性规则 —— 字段是否非空
│   ├── 准确性规则 —— 格式、范围、枚举是否正确
│   ├── 一致性规则 —— 跨系统数据是否一致
│   ├── 及时性规则 —— 数据更新是否延迟
│   └── 唯一性规则 —— 主键是否重复
│
├── 第二层：监控执行层（执行引擎）
│   ├── 自动化检核 —— 每日/每小时定时跑批
│   ├── 人工抽查 —— 每月随机抽样复核
│   └── 业务反馈 —— 随时发现问题上报
│
├── 第三层：问题处理层（处理引擎）
│   ├── 问题发现 → 自动告警
│   ├── 问题受理 → 治理团队统一录入
│   ├── 问题分派 → 业务类→Steward / 技术类→IT开发
│   ├── 问题处理 → Steward确认业务规则 / IT修复系统
│   ├── 问题验证 → 治理团队复核
│   └── 问题归档 → 记录台账
│
└── 第四层：报告展示层（展示层）
    ├── 实时质量看板 —— 大屏展示核心指标
    ├── 日报 —— 每日自动发送
    ├── 周报 —— 每周自动生成
    └── 月报 —— 每月人工整理
```

### 1.2 各层之间的关系

```
┌─────────────────────────────────────────────────────────┐
│  检核规则层（定义"什么是问题"）                            │
│  例：mobile 字段必须匹配正则 ^1[3-9]\d{9}$               │
│  → 详见：[[模板-数据质量检核规则]]                        │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  监控执行层（执行"检查是否有问题"）                        │
│  例：每日凌晨 2:00 自动跑批，检查 mobile 格式合规率        │
│  → 详见：[[模板-数据质量监控方案]]                        │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  问题处理层（处理"发现问题后怎么办"）                      │
│  例：发现 45 条手机号不合规 → 治理团队录入+撰写业务描述    │
│       → 判断为系统缺陷 → 分派 IT 李工修复（抄送 Steward）  │
│  → 详见：[[模板-数据问题处理闭环流程]]                    │
└─────────────────────────────────────────────────────────┘
                          ↓
┌─────────────────────────────────────────────────────────┐
│  报告展示层（展示"质量状况如何"）                          │
│  例：客户数据质量得分 96 分，较上周提升 2 分               │
│  → 详见：[[模板-数据质量报告]]                            │
└─────────────────────────────────────────────────────────┘
```
